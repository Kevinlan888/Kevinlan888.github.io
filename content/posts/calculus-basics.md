## 22. 公式速查与复习顺序 {#section-22}

### 22.1 优先记住的公式与条件

| 知识点 | 公式或规则 | 条件／提醒 |
|---|---|---|
| 不等式 | 乘除负数，不等号反向 | 先判断乘除量的符号 |
| 平方差 | $a^2-b^2=(a-b)(a+b)$ | 不要与完全平方混淆 |
| 平方开方 | $\sqrt{x^2}=\lvert x\rvert$ | 结果非负 |
| 根号拆乘积 | $\sqrt{ab}=\sqrt a\sqrt b$ | $a,b\ge0$ |
| 二次方程 | $x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}$ | $a\ne0$，实根要求 $\Delta\ge0$ |
| 零次方 | $a^0=1$ | $a\ne0$ |
| 指数相乘 | $a^m a^n=a^{m+n}$ | 任意实数指数时取 $a>0$ |
| 负指数 | $a^{-x}=1/a^x$ | 任意实数指数时取 $a>0$ |
| 指数与对数 | $\ln(e^x)=x$ | $x\in\mathbb R$ |
| 对数与指数 | $e^{\ln x}=x$ | $x>0$ |
| 正弦值域 | $-1\le\sin x\le1$ | 实数输入，不限范围时两端都能取到 |
| 向下取整 | $\lfloor x\rfloor=n\iff n\le x<n+1$ | $n\in\mathbb Z$ |
| 反函数 | $f^{-1}(f(x))=x$ | $x$ 在原函数定义域内 |

### 22.2 每次计算前检查

1. 分母是否可能为零？
2. 偶次根号内是否非负？
3. 对数真数是否严格大于零？
4. 移项、去括号时是否漏掉负号？
5. 约分约的是公因子吗？原定义域限制保留了吗？
6. 区间端点能否取到？
7. 求反函数时，有没有按原定义域舍去不合要求的解？

### 22.3 建议复习顺序

1. **代数运算**：正负数 → 分数 → 移项 → 不等式 → 因式分解 → 根号 → 二次方程。
2. **指数与对数**：指数规则 → $e$ → 对数 → $\ln$。
3. **函数基础**：集合与区间 → 定义域与值域 → 正弦、符号、取整函数。
4. **函数关系**：复合函数 → 分段函数 → 反函数 → 恒等函数。
5. **综合与衔接**：独立重做[第 21 节例题]({{< relref "/posts/calculus-basics-inverse-example.md#section-21" >}})，再复习极限的含义。

每一块先做到“看懂规则和例子”，再做到“遮住答案算一遍”，最后练习在综合题中认出该用哪条规则。
